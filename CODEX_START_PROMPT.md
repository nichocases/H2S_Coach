# Prompt inicial para Codex

Copia y pega este mensaje en Codex después de abrir la carpeta del proyecto:

> Vamos a construir Inline Hockey Coach desde cero mediante Spec-Driven Design. Es una app móvil Flutter para entrenadores de hockey sobre patines en línea, con backend FastAPI y funcionamiento offline-first.
>
> 1. Lee completamente `AGENTS.md`, `specs/constitution.md` y todos los archivos de `specs/001-mvp/`.
> 2. Confirma el alcance, las reglas de arquitectura y los comandos de validación.
> 3. Identifica contradicciones o información indispensable que falte. No preguntes por preferencias que ya estén fijadas en las especificaciones.
> 4. Si no hay bloqueos, implementa solamente la Fase 0, tareas T001–T005 de `tasks.md`.
> 5. Antes de editar, muestra un plan breve y los archivos que crearás.
> 6. Usa Flutter/Dart para todo el frontend. No sustituyas Flutter por React Native, Expo, PWA ni otra tecnología.
> 7. Ejecuta todas las validaciones de la fase y corrige los fallos producidos por tus cambios.
> 8. Al terminar, reporta tareas completadas, pruebas ejecutadas, resultados y riesgos pendientes. No avances a la Fase 1 sin aprobación.

Para las fases siguientes, usa los prompts de `specs/001-mvp/quickstart.md`.
